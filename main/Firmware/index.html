Firmware

Firmware updates can add features, fix defects, and improve compatibility with the ifmVisionAssistant and ifm3d library. Before updating an O3C, verify that the target firmware is supported for the device and software versions in your system.

Firmware workflow

  1. Please contact the ifm support team at support.efector.object-ident@ifm.com to get the latest firmware version.

  2. Save the current device configuration before updating. Firmware changes can reset or alter configuration parameters.

  3. Follow How to update the firmware, using a static IP address and a stable power and Ethernet connection.

  4. After the update, confirm the firmware version, restore or review the configuration, and verify that the camera produces the expected data.

Important

Do not interrupt power or the Ethernet connection while a firmware update is in progress. The camera reboots after the update and may be temporarily unavailable during startup.

ROS compatibility

Coming soon

ROS drivers for the O3C camera are under development. Follow the ifm3d-ros2 GitHub repository for latest updates.
