Processing parameters

The O3C provides several filters to handle specific ToF artifacts. The diagram below shows the filtering process applied to the ToF data to produce the distance measurements. Each filter can be enabled, disabled or fine-tuned to fit your application.

Type and default values can change depending on the firmware version, so we recommend reading them from the schema. For example, to check the type and default value of maxDistNoise for port0:

$ ifm3d o3cxxx config getSchema | jq .properties.ports.properties.port0.properties.processing.properties.diParam.properties.maxDistNoise
{
  "default": 0.05,
  "description": "Maximum distance noise, given as the standard deviation in [m]. (0.0: disable check).",
  "maximum": 1,
  "minimum": 0,
  "type": "number"
}

from ifm3dpy.device import O3C
o3c = O3C("192.168.0.69")
o3c.get_schema()["properties"]["ports"]["properties"]["port0"]["properties"]["processing"]["properties"]["diParam"]["properties"]["maxDistNoise"]
{'default': 0.05, 'description': 'Maximum distance noise, given as the standard deviation in [m]. (0.0: disable check).', 'maximum': 1.0, 'minimum': 0.0, 'type': 'number'}

Note

Configuration parameters marked with the attribute [conf] can only be modified when the port or application is in the CONF state. Ensure the system is in this state before attempting to change these settings.

Available filters

  • Maximum distance noise — keeps only pixels whose distance noise is below a threshold, removing the noisiest pixels (e.g. ambient light) while preserving usable data. Lower it for high-precision measurement (box dimensioning); raise it to keep all pixels (obstacle detection).

  • Minimum amplitude and minimum reflectivity — a pixel is valid only if the received energy (amplitude) is above the threshold. Lower it for low-reflectivity targets (< 10 %, matte black) or negative obstacles (stairs), and enable a noise filter when you do.

  • Adaptive noise bilateral filter — reduces distance noise while preserving edges (recommended). A larger mask (e.g. 7x7) usually improves quality.

  • Median filter — cheaper than the bilateral filter but rounds corners and preserves edges less well; useful for in-motion cases.

  • Temporal filter — reduces noise by integrating over multiple frames; best for static scenes.

  • Mixed pixel filter — removes “flying” pixels on object edges. Disable it if those edge pixels are useful (e.g. negative obstacle detection).

  • Symmetry threshold — mitigates motion blur by allowing less signal symmetry; more tolerance increases distance noise.
