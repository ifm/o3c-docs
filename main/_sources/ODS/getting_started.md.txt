# Getting started with ODS

Check out this video to get started with ODS:
:::{youtube} Icvgb2IczIQ

Alternatively, you can read through the steps below.

## What you need

- An **O3C device**, powered and connected to your laptop via Ethernet.
- The **ifm Vision Assistant** installed on your laptop — [download the latest version from ifm.com](https://www.ifm.com).

For hardware setup and wiring details, see [the unboxing guide](../GettingStarted/Unboxing/hw_unboxing.md).

## Step 0: Connect and verify

Open the ifm Vision Assistant and confirm that it can connect to the O3C and receive data before proceeding.

## Step 1: Extrinsic calibration

Use the calibration wizard in the ifm Vision Assistant to calibrate the camera.

```{image} img/open_iVA_calib_wizard.drawio.svg
:alt: Open the Vision Assistant calibration wizard
:width: 1080px
:align: center
```
<!-- ![Open the Vision Assistant calibration wizard](img/open_iVA_calib_wizard.png) -->

<!-- ![Calibrate the 3D camera like a vehicle from camera](img/calibrate_3D_cam.png) -->

```{image} img/calibrate_3D_cam.drawio.svg
:alt: Calibrate the 3D camera like a vehicle from camera
:width: 1080px
:align: center
```

- By default, the calibration wizard uses the default calibration for the O3C. Because `PORT0` (3D port), `PORT1` (2D port), and `PORT6` (IMU port) are calibrated to the camera reference system, you can use the `Sync ports` button to synchronize the extrinsic calibration across all ports.
- To manually calibrate the camera, click on "Rotate like vehicle front camera".
- Choose the camera orientation, then adjust the roll/pitch and yaw as required. Do not configure the technical rotations; the system calculates them automatically.
- Adjust the translation values relative to the vehicle origin reference system.
- Select `Sync ports` to synchronize the extrinsic calibration across all ports.

## Step 2: Create an ODS application

In the "Application" tab, create an ODS application instance.

```{image} img/create_ods_app.drawio.svg
:alt: Create an ODS application
:width: 1080px
:align: center
```
<!-- ![Create an ODS application](img/create_ods_app.png) -->

An application instance is created with default settings. By default, PORT0 is added to the list of ports for the ODS app to use.

<!-- ![Default ODS application](img/default_ods_app.png) -->

```{image} img/default_ods_app.drawio.svg
:alt: Default ODS application
:width: 1080px
:align: center
```

:::{note}
When you first instantiate the application, diagnostic messages may appear at the bottom of the screen.
The ODS application checks the vehicle's motion, and these checks may take some time to pass while the application is running. The messages typically disappear after ODS initializes properly.
:::

## Step 3: Start ODS

To start ODS, you can simply set the `state` parameter to `"RUN"`:

## Next steps

At this point ODS is running with default settings. The next step is to configure it for your specific vehicle and environment:

- **[Configuration](Configuration/configuration)** — set up detection zones, grid parameters, ego-motion source, overhanging loads, and interference mitigation.
- **[Mounting](Integration/hardware)** — verify that your camera placement meets the clearance areas and heat dissipation requirements.
****- **[Extrinsic calibration](ExtrinsicCalibration/index_extrinsic_calibration)** — improve the camera-to-vehicle calibration for production-quality detection.
