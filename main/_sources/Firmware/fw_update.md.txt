# How to update the firmware

:::{warning}
The firmware update should only be performed using a static IP address. It is recommended to use the default static IP address `192.168.0.69`.
:::

## Download the firmware
The firmware image is available on the [ifm.com](https://www.ifm.com/) website. Navigate to the site and follow the steps below:
- Create an account (if you do not already have one) and log in.
- Use the search bar to find the article number. If you have pre-release sample units, for example M04556 please contact us for the latest SWUpdate file.
- Navigate to the article page an click on the "Downloads" tab.
- Select the firmware from the list. It will start downloading the file.

### (Optional) Save the current configuration
Depending on the starting and target firmware versions, the configuration might not be fully preserved after an update. To make sure you do not lose your configuration, we recommend saving it locally before performing the update.

You can for example do so using the command line interface:
```bash
ifm3d o3cxxx config get > o3c_config.json
```

### With the ifmVisionAssistant

Download the ifmVisionAssistant from https://www.ifm.com/us/en/product/OVP800?tab=documents.

In the instructions below, we expect that the user extracted the downloaded ZIP containing the firmware file.

- Open the Vision Assistant and connect to the O3Cxxx,
- Navigate to the `Device Setup` window and click `Update` under the `Firmware Update` section. The version beside the `Update` button refers to the current version running on O3C camera.
- Select the file and the update process will start.
- Once the update is complete, the device will reboot.

:::{note}
    The firmware update using the iVA Linux AppImage may fail on the first attempt, causing the camera to remain in recovery mode.
    If this happens, refer to [the instructions below](#rebooting-to-productive-mode) to reboot to productive mode, using the ifm3d API.
:::

### Using ifm3d API

To install ifm3d API on your system, please follow the instructions documented in [installation instructions](https://api.ifm3d.com/stable/content/installation_instructions/index.html) based on your operating system.

In the instructions below, replace `<path/to/firmware_image.swu>` with the path to the firmware file you downloaded from [ifm.com](https://www.ifm.com/).

:::::{tabs}
::::{group-tab} CLI
```bash
# Warning, the CLI syntax was updated with ifm3d v1.6.xx.
# Make sure you are using the right API version.
$ ifm3d o3cxxx swupdate flash <path/to/firmware_image.swu>
```
::::
::::{group-tab} c++
```cpp
#include <ifm3d/device/o3c.h>
#include <ifm3d/swupdater/swupdater.h>
...
auto o3c = std::make_shared<ifm3d::O3C>();
auto sw = std::make_shared<ifm3d::SWUpdater>(o3c);
if (sw->FlashFirmware("<path/to/firmware_image.swu>")){
    sw->WaitForProductive();
    std::cout << "System ready!" << std::endl;
}
```
::::
::::{group-tab} Python
```python
from ifm3dpy.swupdater import SWUpdater
from ifm3dpy.device import O3C
o3c = O3C()
sw = SWUpdater(o3c)
if sw.flash_firmware('<path/to/firmware_image.swu>'):
    sw.wait_for_productive()
    print("System ready!")
```
::::
:::::

:::{note}
    The code snippets above do not show how to handle exceptions when they occur in the update process. Please refer to the API documentation for details on the potential exceptions thrown by each function.
:::

### Using Web Interface

**Step 1:** Open the http://<IP_ADDRESS>/api/rpc/v1/com.ifm.efector/ and select method `rebootToRecovery` to reboot the device into recovery mode. When the device boots into recovery mode successfully, it opens the Software update web interface at port `8080`.

- Open the webpage at http://<IP_ADDRESS>:8080
- Drop the **.swu** file. The firmware update begins and the system will boot into productive mode.

### The full example script

We provide a full Python script to help you update the firmware using the API. You can find this script [in the `ifm3d-examples` repository](https://github.com/ifm/ifm3d-examples).
