External Ego Data

Overview

On O3C, the ODS application relies solely on host-provided ego-motion data — the vehicle’s own velocity — for obstacle tracking relative to a moving vehicle.

For the ODS integration, send the following information:

  • vx: longitudinal velocity in m/s

  • vy: lateral velocity in m/s

  • timestamp_ns: timestamp in nanoseconds

The ego-motion data allows ODS to compensate for the vehicle’s own movement between frames. Accumulating evidence over time in this way significantly improves detection performance: obstacles are detected earlier, tracked more stably, and spurious detections are suppressed.

Without valid ego-motion data, this propagation is not possible and the detection quality degrades accordingly. Supplying accurate ego-motion data that meets the requirements below is therefore essential for a well-performing ODS integration.

Requirements for the ego-motion input

Requirement

Value

Update rate

At least 10 Hz, at most 20 Hz

Velocity range

vx and vy must be finite numbers within [-10.0 m/s, 10.0 m/s]

Maximum latency

500 ms (data must not be delayed by more than 500 ms)

Maximum clock drift

0.5 %

Clock jumps

Permitted, but not more than once per minute

Important

**Timestamp synchronization is not required.** The timestamps do not have to be
synchronized with the camera, and NTP (Network Time Protocol) synchronization is
not needed. However, each timestamp must be generated as close as possible to the
actual measurement it belongs to. A timestamp taken long after the velocity was
measured (for example, at the end of a processing chain) degrades the quality of
the synchronization performed inside ODS.

Timing and synchronization requirements

The external ego-motion signal must be provided with low latency and a measurement timestamp that is as close as possible to the actual motion event. NTP synchronization with the camera is not required, but the signal must still be time-accurate enough for ODS to align it with its internal motion estimate.

Until synchronization is established, the external ego-motion data is not used for tracking. During startup or while the vehicle is stationary, the diagnostic ODS_VELOCITY_UNAVAILABLE may remain active until the vehicle starts moving and synchronization is established. If the input is delayed, irregular, or stamped late, ODS performance is limited.

Warning

Complete and verify the extrinsic calibration of the camera head and the IMU
before commissioning ODS. External ego-motion data does not replace this
calibration. If the IMU is not calibrated correctly relative to the camera and
the vehicle, ODS cannot reliably reconcile its own velocity estimate with the
velocity provided by the host. ODS performance may be degraded, and repeated
velocity-related diagnostics may be reported.

Troubleshooting

If ODS_VELOCITY_UNAVAILABLE or other velocity-related/ego-motion related diagnostics occur:

  1. Check whether the vehicle has moved since the last ODS startup. Synchronization only completes once the vehicle is in motion.

  2. Verify that the input meets the requirements, in particular the update rate, the latency, and the timestamp quality.

  3. Verify the extrinsic calibration of the camera head and the IMU, and repeat the initial standstill checks. Incorrect IMU calibration can cause the ODS velocity estimate to diverge from the velocity supplied by the host, even when the external ego-motion data is available.

Example Code

"""
Send ego-motion data to ODS via O3C connection.
"""
import logging
import struct
import time

from ifm3dpy.device import O3C, Parameter, SetTemporaryApplicationParameter
from ifm3dpy.framegrabber import FrameGrabber

logger = logging.getLogger(__name__)


class O3CConnection:
    """Manages O3C TCP connection with automatic reconnection"""

    def __init__(self, ip_address):
        self.ip_address = ip_address
        self._o3c = O3C(ip_address)
        self._fg: FrameGrabber | None = None
        self._current_port = None
        self.connected = False

    def find_ods_port(self):
        """Discover the ODS PCIC port dynamically."""
        apps = self._o3c.get().get("applications", {}).get("instances", {})
        for inst in apps.values():
            if inst.get("class") == "ods":
                port = inst.get("data", {}).get("pcicTCPPort")
                logger.info("Discovered ODS PCIC port: %s", port)
                return port
        logger.error("No ODS application found on device!")
        return None

    def _fg_async_error(self, id: int, message: str):
        logger.error("FrameGrabber async error (id=%s): %s", id, message)
        # Mark broken
        self.connected = False

    def connect(self):
        """Connect to O3C (ODS) via FrameGrabber."""
        try:
            # Discover port fresh each time
            port = self.find_ods_port()
            if port is None:
                logger.debug("O3CConnection.connect: no ODS app found")
                self.connected = False
                return False

            # Port changed or no FG exists, recreate FG
            if port != self._current_port:
                logger.info("ODS port changed: %s → %s", self._current_port, port)
                self._current_port = port

            # Close previous FG if present
            if self._fg:
                try:
                    self._fg.stop().wait()
                except Exception:
                    pass
            try:
                # Create new FrameGrabber
                self._fg = FrameGrabber(self._o3c, self._current_port)
                self._fg.on_async_error(self._fg_async_error)
                self._fg.start([]).wait()
                self.connected = True
                logger.info("Connected to ODS at port %s", self._current_port)
                return True
            except Exception as e:
                logger.error("FrameGrabber start error: %s", e)
                self.connected = False
                return False

        except Exception as e:
            logger.error("O3C connection error: %s", e)
            self.connected = False
            return False

    def send_velocity(self, vx: float, vy: float, timestamp_ns: int):
        """Send ego-motion velocity (vx, vy, timestamp) to ODS."""

        # Ensure connected
        if not self.connected or not self._fg or not self._fg.is_running():
            if not self.connect():
                return False

        try:
            packet = struct.pack("<ffQ", float(vx), float(vy), int(timestamp_ns))
            cmd = SetTemporaryApplicationParameter(
                parameter=Parameter.ODS_MOTION_DATA, data=bytearray(packet)
            )
            # synchronous send_command
            self._fg.send_command(cmd)
            return True

        except Exception as e:
            logger.warning("send_velocity failed: %s", e)
            # mark broken so next loop we re-discover and reconnect
            self.connected = False
            return False

    def close(self):
        """Close the connection."""
        try:
            if self._fg:
                self._fg.stop().wait()
        except Exception:
            pass
        finally:
            self.connected = False
            self._current_port = None


def main():
    logging.basicConfig(level=logging.INFO)
    o3c_conn = O3CConnection("192.168.0.69")

    timeout_s = 120
    start = time.monotonic()
    while not o3c_conn.connected:
        if time.monotonic() - start >= timeout_s:
            logger.error("Could not connect within %d seconds. Exiting.", timeout_s)
            o3c_conn.close()
            raise SystemExit(1)
        logger.info("Retrying connection...")
        o3c_conn.connect()
        time.sleep(1)

    logger.info("Connected, sending ego-motion data...")
    try:
        while True:
            try:
                # Sending dummy ego-motion data:
                # vx=0.0 m/s, vy=0.0 m/s, timestamp=current time in ns

                if not o3c_conn.send_velocity(0.0, 0.0, time.time_ns()):
                    logger.warning("send_velocity failed, reconnecting...")
                    o3c_conn.connect()
            except Exception as e:
                logger.error("Unexpected error: %s", e)
            time.sleep(0.1)  # ~10 Hz
    except KeyboardInterrupt:
        logger.info("KeyboardInterrupt received, exiting.")
    finally:
        o3c_conn.close()


if __name__ == "__main__":
    main()

/*

 *
 * Send ego-motion data to ODS using:
 * ifm3d::O3C::SetTemporaryApplicationParameter(Parameter::ODS_MOTION_DATA, ...)
 */

#include <chrono>
#include <cstdint>
#include <cstring>
#include <exception>
#include <ifm3d/device/o3c.h>
#include <ifm3d/device/pcic_command.h>
#include <ifm3d/fg/frame_grabber.h>
#include <iostream>
#include <memory>
#include <optional>
#include <string>
#include <thread>
#include <utility>
#include <vector>

namespace
{
  // This is the PCIC command object that carries ODS temporary parameter data.
  using TemporaryApplicationParameterCommand =
      ifm3d::O3C::SetTemporaryApplicationParameter;

  bool
  IsO3CReachable(ifm3d::O3C &o3c)
  {
    try
    {
      (void)o3c.Ports();
      return true;
    }
    catch (...)
    {
      return false;
    }
  }

  std::optional<std::uint16_t>
  FindODSPcicPort(ifm3d::O3C &o3c)
  {
    const auto config = o3c.Get();
    const auto &instances = config.at("applications").at("instances");

    for (const auto &port_info : o3c.Ports())
    {
      if (port_info.type != "app")
      {
        continue;
      }

      const auto app_port = port_info.port;

      const auto instance_it = instances.find(app_port);
      if (instance_it == instances.end() || !instance_it->is_object())
      {
        continue;
      }
      if (instance_it->value("class", "") != "ods")
      {
        continue;
      }

      const std::uint16_t pcic_port = port_info.pcic_port;

      std::clog << "Discovered ODS instance '" << app_port << "' on PCIC port "
                << pcic_port << std::endl;
      return pcic_port;
    }

    return std::nullopt;
  }

  // Append a 32-bit value as little-endian bytes.
  void
  AppendU32Le(std::vector<std::uint8_t> &out, std::uint32_t value)
  {
    out.push_back(static_cast<std::uint8_t>(value & 0xFFu));
    out.push_back(static_cast<std::uint8_t>((value >> 8) & 0xFFu));
    out.push_back(static_cast<std::uint8_t>((value >> 16) & 0xFFu));
    out.push_back(static_cast<std::uint8_t>((value >> 24) & 0xFFu));
  }

  // Append a 64-bit value as little-endian bytes.
  void
  AppendU64Le(std::vector<std::uint8_t> &out, std::uint64_t value)
  {
    for (int shift = 0; shift < 64; shift += 8)
    {
      out.push_back(static_cast<std::uint8_t>((value >> shift) & 0xFFu));
    }
  }

  std::vector<std::uint8_t>
  BuildMotionPayload(float vx_mps, float vy_mps, std::uint64_t timestamp_ns)
  {
    // ODS_MOTION_DATA expects exactly: float vx, float vy, uint64 timestamp_ns
    // encoded as little-endian bytes.
    std::vector<std::uint8_t> payload;
    payload.reserve(16);

    std::uint32_t vx_bits = 0;
    std::uint32_t vy_bits = 0;
    std::memcpy(&vx_bits, &vx_mps, sizeof(vx_mps));
    std::memcpy(&vy_bits, &vy_mps, sizeof(vy_mps));

    AppendU32Le(payload, vx_bits);
    AppendU32Le(payload, vy_bits);
    AppendU64Le(payload, timestamp_ns);
    return payload;
  }

  std::uint64_t
  NowNs()
  {
    const auto now = std::chrono::system_clock::now().time_since_epoch();
    return static_cast<std::uint64_t>(
        std::chrono::duration_cast<std::chrono::nanoseconds>(now).count());
  }
}

int main(int argc, char **argv)
{
  const std::string ip = (argc > 1) ? argv[1] : "192.168.0.69";
  const float vx_mps = (argc > 2) ? std::stof(argv[2]) : 0.0F;
  const float vy_mps = (argc > 3) ? std::stof(argv[3]) : 0.0F;
  const int rate_hz = (argc > 4) ? std::stoi(argv[4]) : 10;

  if (rate_hz <= 0)
  {
    std::cerr << "rate_hz must be > 0" << std::endl;
    return 2;
  }

  const auto period = std::chrono::milliseconds(1000 / rate_hz);

  std::clog << "IP=" << ip << ", vx=" << vx_mps << " m/s, vy=" << vy_mps
            << " m/s, rate=" << rate_hz << " Hz" << std::endl;

  auto o3c = std::make_shared<ifm3d::O3C>(ip);

  while (true)
  {
    try
    {
      if (!IsO3CReachable(*o3c))
      {
        std::cerr << "O3C is not reachable. Retrying..." << std::endl;
        std::this_thread::sleep_for(std::chrono::seconds(1));
        continue;
      }

      const auto ods_port = FindODSPcicPort(*o3c);
      if (!ods_port)
      {
        std::cerr << "No ODS application found. Retrying..." << std::endl;
        std::this_thread::sleep_for(std::chrono::seconds(1));
        continue;
      }

      // Temporary application parameters are sent over the ODS PCIC stream,
      // so we open a FrameGrabber on the discovered ODS PCIC port.
      auto fg = std::make_shared<ifm3d::FrameGrabber>(o3c, *ods_port);
      fg->OnAsyncError([](int id, const std::string &message)
                       { std::cerr << "FrameGrabber async error (id=" << id
                                   << "): " << message << std::endl; });
      fg->Start({}).wait();

      std::clog << "Connected to ODS on port " << *ods_port
                << ". Sending ODS_MOTION_DATA..." << std::endl;

      while (true)
      {
        const auto timestamp_ns = NowNs();
        // Raw motion bytes that become the 'data' field of ODS_MOTION_DATA.
        const auto payload = BuildMotionPayload(vx_mps, vy_mps, timestamp_ns);

        // 2103 == ODS_MOTION_DATA. The enum keeps this readable and safe.
        TemporaryApplicationParameterCommand command(
            TemporaryApplicationParameterCommand::ODS_MOTION_DATA,
            payload);

        fg->SendCommand(command).get();
        std::clog << "Sent ego-motion: vx=" << vx_mps << ", vy=" << vy_mps
                  << ", t=" << timestamp_ns << " ns" << std::endl;
        std::this_thread::sleep_for(period);
      }
    }
    catch (const std::exception &ex)
    {
      std::cerr << "Send loop error: " << ex.what() << " - reconnecting..."
                << std::endl;
      std::this_thread::sleep_for(std::chrono::seconds(1));
    }
  }

  return 0;
}
